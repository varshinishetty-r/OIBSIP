# 🔐 Login Authentication System

## 📌 Project Description

A responsive Login Authentication System developed using HTML, CSS, and JavaScript. The system allows users to register, login, access a protected dashboard, and logout securely.

## 🎯 Objective

To build a simple authentication system with user registration, login validation, password security, session management, and protected page access.

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* localStorage
* sessionStorage
* SHA-256 Hashing

## ✨ Features

* User registration with username and email
* Password validation with minimum 8 characters and at least 1 number
* Duplicate username/email detection
* Login using username or email
* Incorrect credential error handling
* Show/Hide password option
* SHA-256 password hashing
* Protected dashboard
* Login session management
* Logout functionality
* Responsive user interface
