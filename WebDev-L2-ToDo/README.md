# To-Do Web App

A simple and interactive **To-Do Web App** built to help users organize and manage their daily tasks efficiently.

## 📌 About the Project

This project is developed as part of the **Oasis Infobyte Web Development and Designing Internship – Task 3**. It allows users to add, edit, complete, and delete tasks through a clean and responsive interface.

Tasks are organized into **Pending Tasks** and **Completed Tasks**, with counters to help users keep track of their progress.

## ✨ Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Delete tasks
* Separate Pending and Completed task lists
* Display pending and completed task counts
* Task timestamps
* Save tasks using `localStorage`
* Responsive design
* Friendly empty-state messages

## 🛠️ Technologies Used

* **HTML5** – Structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Functionality and DOM manipulation
* **localStorage** – Task persistence
