# Tribute Page

A visually engaging tribute page created using **HTML5 and CSS3** to honor and showcase the life, achievements, and contributions of an inspiring public figure.

## 📌 Project Overview

This project is designed as part of the **Oasis Infobyte Web Development and Designing Internship**. The page presents a biography, important achievements, timeline, and a notable quote in a clean and responsive layout.

## ✨ Features

* 🏷️ Subject's name with a meaningful tagline
* 🖼️ Prominent royalty-free image
* 📖 Biography and tribute section
* 🏆 Key achievements and milestones
* 🕰️ Timeline of important events
* 💬 Distinctive quote section
* 🎨 Multiple background colours for different sections
* 🔤 Different font styles for headings and body text
* 📱 Fully responsive design
* 💻 Built using HTML5 and CSS3

## 🛠️ Technologies Used

* **HTML5** – Page structure and content
* **CSS3** – Styling, layout, typography, colours, animations, and responsiveness

## 📂 Project Structure

Tribute-Page/

## 🖥️ Sections Included

1. **Hero Section** – Name, tagline, and prominent image
2. **Biography** – Overview of the subject's life and contributions
3. **Timeline** – Important achievements and milestones
4. **Quote Section** – A notable quote from or about the subject
5. **Footer** – Project and source information

## 📚 Sources

The factual information was researched using reliable sources such as:

* Wikipedia
* Encyclopaedia Britannica
* Wikimedia Commons for royalty-free/public-domain imagery

The written content has been **paraphrased and presented in original wording**.

## 📱 Responsive Design

The webpage is designed to work across different screen sizes, including:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

CSS media queries are used to adapt the layout for smaller screens.

## 🎯 Objective

The objective of this project is to practice:

* Semantic HTML structure
* CSS styling and layouts
* Responsive web design
* Typography and visual hierarchy
* Creating an engaging webpage using HTML and CSS
